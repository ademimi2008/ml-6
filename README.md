Освоить базовый пайплайн обработки текста и построить классификатор на основе векторизованного представления.

## Задание

1. Реализовать функцию очистки текста: приведение к нижнему регистру, удаление пунктуации и цифр, удаление стоп-слов.
2. Провести токенизацию и, при необходимости, стемминг или лемматизацию.
3. Векторизовать очищенный текст через TF-IDF с ограничением словаря (`min_df`, `max_df`) и обучить классификатор.
4. Проанализировать 5 ошибок модели и сформулировать гипотезу о причине каждой.
